# 审美判断手册（aesthetics）

本文件把「好看不好看」翻译成可判定的检查项。四条准则、五条否决信号、一套评审话术，全部面向评审现场：能在一张图前 3 分钟内做出判断，并说出改哪里。

## 0. 三条铁律

1. 先指标，后空间，最后形式。指标不成立的方案，形式再对也不评。
2. 本文所有数值均为工程惯例建议值，用于内部评审可比对，不是规范值，不得写进报建文件。规范值以现行有效版本为准。
3. 任何无法量化的判断，必须给对照物（同一位置的另一版方案、同一气候区的建成案例、同一材料在不同光线下的两张照片）。给不出对照物的主观评价，不作为修改依据。

## 1. 准则一 · 比例与模数

### 1.1 要解决的问题

尺寸各自为政：立面一套模数、铺装一套模数、柱网再一套，结果所有交接处都出现小条碎块。比例失控的另一半原因是层级过多——同一个立面上有五层线脚、四个窗型、三种沟缝，眼睛找不到主次。

### 1.2 判定法（可执行）

| 检查 | 怎么量 | 通过标准（工程惯例建议值） |
|---|---|---|
| 基准模数 | 取立面、平面、铺装三张图，各抽 10 个主要尺寸，除基准模数看余数 | ≥80% 尺寸被同一模数整除；建筑取 300mm，构造取 100mm，铺装取 300mm 或 600mm |
| 模数一致性 | 把建筑与景观的所有尺寸对 300mm 取余 | 两专业不得各用一套模数；不一致时以建筑 300mm 为准，景观向上取整 |
| 重复单元层级 | 数立面上「可命名的重复单元」有几级 | ≤3 级（如：开间 → 窗洞 → 分格）；超过 3 级删中间一层 |
| 窗宽系列 | 取同一立面任 3 个窗宽 | 呈整数倍关系（如 600/900/1200/1500/1800 系列）；不呈整数倍即判不合格 |
| 竖向分段 | 量基座、中段、檐口三段高度 | 建议接近 1:3:0.5–1；偏离超过一倍时须给理由（功能、结构或遮阳） |
| 踏步与台明 | 量踏步宽与高 | 宽 300–350mm、高 120–150mm；同一跑内高差不齐即改 |
| 铺装与场地尺寸 | 场地净宽 ÷ 板材规格 | 余量 ≥1/2 板宽；出现 <5cm 小条即重新排板 |
| 缝宽 | 量同一立面／铺装的缝宽极差 | 极差 ≤2mm，且缝宽 ≥8mm（小于 8mm 无法施工且会被填缝剂吃掉） |

### 1.3 不合格即改的三种典型

| 现象 | 病因 | 改法 |
|---|---|---|
| 立面上某扇窗明显偏窄 | 开窗模数是「排布出来的」而非「选出来的」 | 回到窗宽系列重排，宁可减少窗数也不改单窗尺寸 |
| 铺装收边出现一排碎砖 | 排版从中心向两侧发散 | 改为从主视线一侧起排，余量收到背视线侧 |
| 柱网与车位排布打架 | 柱距不是「车位宽 × 整数 + 柱宽」 | 先定车位模数再定柱网，8.1m 与 8.4m 必须试排后二选一 |

### 1.4 脚本对接

AEST-MOD-01 判「基准模数整除主要尺寸」，通过线 ≥80%；不通过时先向模数取整，再声明例外并给理由。

### 1.5 基准模数的决议流程（一次定死）

1. 取柱网候选值（8.1m / 8.4m / 9.0m），分别试排车位，选车位损失最小的一个。
2. 用柱网反推开间模数（通常 300mm 的整数倍），确认开间能被 3 整除以便门窗系列对齐。
3. 铺装模数取建筑的 1/2 或 1/1（300mm 或 600mm），不得另立一套。
4. 把决议写进 design.json 的 module_mm 与 facade.module_mm，两个字段必须同值。
5. 后续任何尺寸在出图前对模数取余，余数不为 0 的，要么改尺寸，要么在图纸上标注为例外并给理由。

### 1.6 比例失控的三个早期信号

| 信号 | 读法 | 处理时机 |
|---|---|---|
| 方案阶段出现 5cm 以下小条 | 铺装排板未从主视线起排 | 当场重排，不留到深化 |
| 同一立面窗型超过 3 种 | 每次改功能就加一种窗 | 立即并回 3 种以内 |
| 立面上线脚超过 3 道 | 用线脚掩盖材料交接 | 删线脚，改材料收口 |

## 2. 准则二 · 材料与构造真实性

### 2.1 要解决的问题

图纸上的「质感」在施工现场不成立：贴皮假装实砌、涂料假装清水混凝土、铝板折边假装石材倒角。真实性问题不是审美偏好，而是能不能做出来、五年后长什么样。

### 2.2 判定法（可执行）

| 检查 | 怎么量 | 通过标准（工程惯例建议值） |
|---|---|---|
| 主材数量 | 数立面上可命名的外露主材 | ≤3 种；前 3 种面积占比 ≥85%；其余只能作为收边或五金 |
| 材料本色 vs 仿制 | 逐个材料问「它的颜色来自材料本身还是来自涂层」 | 结构性外露材料须用本色；仿制只允许用于非近人尺度的远景体量 |
| 表现与构造一致 | 每个外露构件是否有 1:20／1:10 节点大样 | 缺节点即判「不可施工的装饰」；节点须反映板厚、折边半径与固定方式 |
| 接缝可施工性 | 量板缝、收边宽度 | ≥8mm；收边宽度须大于「板厚 + 折边半径 + 公差」 |
| 砌筑即装饰 | 看砌块的排列是否反映受力与砌法 | 该露砌体就按砌法排版（错缝、转角咬合）；不得用「假缝」画在涂料上 |
| 旧材回用 | 问强度等级、含水率、来源与可再获量 | 有检测与来源；只在一个位置试做样板后推广 |
| 湿贴 vs 干挂 | 看高度、板块尺寸与基层 | 超过湿贴适用范围必须干挂；不得为省造价把大板湿贴到高处 |
| 泛碱与污流 | 看檐口、窗台、压顶是否有滴水与坡度 | 每个水平面有找坡与滴水；无处理的水平面即未来污渍带 |

### 2.3 不合格即改的三种典型

| 现象 | 病因 | 改法 |
|---|---|---|
| 立面 4 种以上材料争主次 | 每种材料都想表达 | 定 1 个主材（≥50%）、2 个辅材，其余全部降为收边或取消 |
| 转角处材料接不上 | 只画了立面没画节点 | 补 1:10 转角节点；做不出就换材料 |
| 三年后出现竖向污流 | 压顶无滴水、无找坡 | 压顶加 3%–5% 找坡与滴水线；挑出 ≥30mm（工程惯例建议值） |

### 2.4 立面材料表模板（缺列即不合格）

| 列 | 填法 | 判定 |
|---|---|---|
| 编号 | M01 起顺序编 | 不得重号 |
| 材料名 | 具体到产地／标号／规格 | 「石材」不合格，「芝麻灰花岗岩 30mm 火烧面」合格 |
| 部位 | 外墙／屋面／压顶／收边 | 收边类不计入主材数量 |
| 面积占比 | 实测，总和 100% | 前三类之和 ≥85% |
| 本色／涂装 | 二选一 | 外露结构材料须为本色 |
| 节点图号 | 指向 1:20／1:10 大样 | 空即判不合格 |
| 采购可行性 | 市场可得／需订制／需打样 | 需订制的必须给交期与最小起订量 |

## 3. 准则三 · 光影与季节

### 3.1 要解决的问题

同一个体量，在正午与冬季下午是两个建筑。只出一张「效果时刻」的天空渲染图，等于放弃了设计的一半：没人知道冬天这个院子有没有太阳、夏天这条廊子有没有阴影。

### 3.2 判定法（可执行）

| 检查 | 怎么量 | 通过标准（工程惯例建议值） |
|---|---|---|
| 光影组数 | 数校核记录 | 9 组 = 3 个日期（冬至、夏至、春秋分）× 3 个时刻（09:00、12:00、15:00） |
| 低角度覆盖 | 查太阳高度角 | 至少 1 组太阳高度角 <35°，否则等于没校核冬季 |
| 公共空间阴影率 | 在 9 组图上量主要活动场地的阴影覆盖 | 夏季正午遮阴 ≥30%；冬季正午受晒 ≥30%（同一块场地两个值都要满足） |
| 檐下深度 | 量挑檐挑出与其下净高 | 南向挑檐挑出约为层高的 0.3–0.5 倍（工程惯例建议值），保证夏季遮阳冬季进光 |
| 剖面取景 | 查每条主要剖面是否标了采光口位置与高度 | 每个主要公共空间至少 1 条剖面穿过，并标采光口 |
| 季节变化 | 查落叶与常绿比例、观花期表 | 落叶乔木占比与气候匹配（北方宜高、南方可低）；至少 2 个季节有可看之物 |
| 时间一致性 | 对比分析图与效果图的光向 | 光向必须一致；不一致即视为「分析图与设计图两张皮」 |

### 3.3 不合格即改的两种典型

| 现象 | 病因 | 改法 |
|---|---|---|
| 效果图永远逆光唯美 | 只挑了出图时刻 | 强制补 9 组，用冬至 09:00 与夏至 15:00 两张做汇报首页 |
| 院子冬天全阴 | 体量间距只按指标算，未做遮挡校核 | 降北侧体量高度或加大间距；把冬季受晒作为体量调整的第一约束 |

### 3.4 脚本对接

AEST-LIGHT-01 判「9 组光影校核齐备且含低角度」，light_checks 字段须逐组登记日期、时刻与太阳高度角。

### 3.5 光影校核记录表模板

| 列 | 填法 |
|---|---|
| 组号 | L01–L09 |
| 日期 | 冬至／夏至／春秋分 |
| 时刻 | 09:00／12:00／15:00 |
| 太阳高度角／方位角 | 逐组给数值，不得只写「上午」 |
| 校核对象 | 主要活动场地、主入口、中庭、主导墙面 |
| 阴影覆盖率 | 实测百分比 |
| 结论 | 通过／需调体量或加遮阳，并写明改什么 |

读数纪律：同一场地在夏季正午与冬季正午的结论必须同时给出；只给一组视为未校核。

## 4. 准则四 · 色彩克制

### 4.1 要解决的问题

色彩失控的典型形态不是「艳」，而是「多」：五种色相各占 20%，任何一处都不构成主色，眼睛无法形成记忆点。

### 4.2 判定法（可执行）

| 检查 | 怎么量 | 通过标准（工程惯例建议值） |
|---|---|---|
| 色相数 | 数可命名色相（不含黑白灰） | ≤5；超出即删到 5 以内 |
| 主色占比 | 量占比第一的色相面积 | ≥50% |
| 高饱和占比 | 量高饱和色（近纯色）面积 | ≤10%，且只能用于标识、门、一处重点 |
| 明度极差 | 量最亮与最暗主材的明度差 | ≤25（0–100 标度）；超过时靠灰度过渡而不是再加色相 |
| 取色来源 | 逐个色相写出来源 | 必须来自场地：土壤、岩石、植被、既有建筑、地方材料；写不出出来源即删 |
| 季节与色彩 | 查植物色彩是否靠花期堆叠 | 冬季（或落叶期）仍有骨架色；不得只靠花期 |
| 光照下的偏差 | 同一材料在 9 组光影下的颜色 | 允许偏差但不得出现「换个时刻变成另一种颜色」的高饱和材料 |

### 4.3 不合格即改的两种典型

| 现象 | 病因 | 改法 |
|---|---|---|
| 儿童区用五色地面 | 用色彩代替空间分区 | 改为材质与高差分区，色彩只保留 1 个标识色 |
| 立面「高级灰」但灰得发脏 | 灰里混了多个色相 | 收敛到同一色相的不同明度，最多加 1 个暖色对比 |

### 4.4 脚本对接

AEST-COLOR-01 判「色相 ≤5、主色 ≥50%、高饱和 ≤10%、明度极差 ≤25」，palette 字段须写明四项实测值。AEST-MAT-01 判主材 ≤3 且前 3 占比 ≥85%。

### 4.5 色彩取值表模板

| 列 | 填法 | 判定 |
|---|---|---|
| 编号 | H01 起顺序编 | — |
| 色相名 | 具体可命名（赭石、灰绿、暖灰） | 「高级色」不合格 |
| 来源 | 土壤／岩石／植被／既有建筑／地方材料 | 写不出来源即删 |
| 面积占比 | 实测 | 第一色相 ≥50% |
| 饱和度档 | 低／中／高 | 高档合计 ≤10% |
| 明度值 | 0–100 | 极差 ≤25 |
| 适用部位 | 墙面／地面／构件／标识 | 高饱和只允许出现在标识与门 |

## 5. 五条否决式不合格信号

以下任一条成立，方案直接判不合格，不再进入形式讨论。判定顺序即列表顺序。

### 5.1 开窗无模数

| 项 | 内容 |
|---|---|
| 看什么 | 同一立面任取 3 个窗宽；再对照平面窗洞与结构梁位 |
| 看到什么算不合格 | 3 个窗宽不呈整数倍；或立面窗与平面窗洞不一致；或分格压不到梁位 |
| 怎么改 | 回到窗宽系列（600/900/1200/1500/1800）重排；先定梁位与柱网，再定分格；一处改，全立面同步 |

### 5.2 材质与色彩超过 4 类且无主次

| 项 | 内容 |
|---|---|
| 看什么 | 数外露主材与主色相，量各自占比 |
| 看到什么算不合格 | 主材 >4 类，或前三类占比 <85%，或没有一种 ≥50% 的主材 |
| 怎么改 | 定 1 主 2 辅，第四类降为收边；色彩收敛到 5 个色相以内并给出来源 |

### 5.3 竖向无法箭头闭合

| 项 | 内容 |
|---|---|
| 看什么 | 在竖向图上沿每条雨水路径画箭头 |
| 看到什么算不合格 | 有路径画不到雨水口或市政接口；出现反坡（坡向与水流方向相反）；或靠「加一个雨水口」掩盖反坡 |
| 怎么改 | 改标高使路径闭合；反坡段必须消除而不是补雨水口；改完重新画箭头直到每条都能闭合 |

### 5.4 剖面不能解释平面

| 项 | 内容 |
|---|---|
| 看什么 | 数每个主要公共空间被几条剖面穿过；查剖面是否标层高、梁高、净高、采光口 |
| 看到什么算不合格 | 有主要公共空间 0 条剖面穿过；或剖面上看不到层高与采光口，只画了轮廓 |
| 怎么改 | 补剖切线穿过该空间；剖面上补齐层高、梁高、净高与采光口四项标注 |

### 5.5 分析图与设计图不一致

| 项 | 内容 |
|---|---|
| 看什么 | 把分析图（流线、日照、光向、风）叠到总图与立面上 |
| 看到什么算不合格 | 分析图上的主入口与总图入口不同位；光向与效果图矛盾；流线穿墙或穿水体；分析图的体量轮廓与总图不一致 |
| 怎么改 | 分析图一律从 design.json 派生，不单独手绘；改图时先改源头再重出分析图 |

备选第六条（仅在尚无 5.1–5.5 证据时使用）：首层平面看不出室外怎么进室内——即从图上看不出到达路径、门厅位置与高差处理。

### 5.6 否决信号的执行顺序与记录

1. 按 5.1 → 5.5 顺序查，前一条成立即停，不再查后面的（避免把结构性问题谈成细节问题）。
2. 记录格式：信号编号 + 图号 + 位置 + 现状值 + 要求值 + 修改动作 + 复核人。
3. 同一条信号在一个项目里出现两次以上，升级为流程问题：检查是否缺前置决策（模数、材料、竖向系统三选一）。
4. 否决不进入投票。评审会上「多数人觉得还行」不改变否决结论。

## 6. 评审话术

### 6.1 三步顺序（不得跳步、不得倒序）

| 步 | 说什么 | 典型句式 |
|---|---|---|
| ① 指标 | 先判方案是否成立：容积率、密度、绿地率、停车、消防、无障碍 | 「容积率 1.42，上限 1.5，余量 5.3%，指标成立——在这个前提下我们再看空间。」 |
| ② 空间关系 | 再说空间能不能用：到达、序列、视线、剖面所解释的关系 | 「从东侧入口到门厅有 1.2m 高差，目前只靠三级台阶，无障碍路径不连续；中庭被两条剖面穿过，采光是成立的。」 |
| ③ 形式 | 最后才说形式：比例、材料、光影、色彩 | 「形式层面有两个问题：窗宽不是整数倍，材质四类没有主次。前者改模数，后者定一主两辅。」 |

三步各自的收尾必须落到「改什么」，不得停在评价。

### 6.2 可直接复用的句式

| 场景 | 句式 |
|---|---|
| 指标超限 | 「当前 X 为 A，限值 B，超出 (A−B)；这不是形式问题，需要砍 C 面积或调整体量，改完再评审。」 |
| 指标余量不足 | 「X 为 A，限值 B，余量只有 P%，低于 3% 的报建安全线；请在下一版留出余量。」 |
| 空间不成立 | 「从 A 到 B 需经过 C，但 C 的净宽／净高只有 D，不满足 E；建议改 F。」 |
| 竖向不闭合 | 「这条路径在 G 点反坡，箭头画不到雨水口；请改标高，不要靠加雨水口解决。」 |
| 剖面缺位 | 「H 空间没有剖面穿过，因此它的采光和净高都未被验证；请补一条穿过 H 的剖切线。」 |
| 交汇未做 | 「乔木定位图与管线图没有叠过，I 处的树压管；请先出 1:500 接口图再讨论种植。」 |
| 形式有偏好但非硬伤 | 「这一点属于偏好，不是硬伤；如果坚持，请给一份对照（同位置另一版或同气候区建成案例）。」 |
| 需要用户拍板 | 「这里有三个选项 A／B／C，各自代价是 ⋯；请选一个，我们据此改图，不再并行推进。」 |

### 6.3 禁用句式

| 禁用 | 原因 | 替换为 |
|---|---|---|
| 「感觉不太协调」 | 无判据，无法执行 | 「三级重复单元过多，删中间一级」 |
| 「再大气一点」 | 无对照物 | 「主材占比从 32% 提到 50% 以上」 |
| 「类似某某项目」 | 借形式而非借手法 | 「借它的单元重复逻辑，改写成我们的 8.4m 柱网」 |
| 「规范要求这样」 | 未给规范名与指标名 | 「按《建筑设计防火规范》的消防车道净宽要求」 |
| 「后面深化再说」 | 把硬伤推给下一阶段 | 当场登记为未定项并给处置期限 |

### 6.4 评审记录格式

每条意见固定四段：位置（图号 + 坐标或轴线）／判据（哪条准则或哪条 rule id）／现状值／要求值。缺任一段的意见不进入修改清单。

## 7. 自检与脚本的对应

| 准则 | 脚本规则 | 触发阶段 | 不通过时的动作 |
|---|---|---|---|
| 比例与模数 | AEST-MOD-01 | 方案、深化 | 尺寸向 300mm 取整，或声明例外并给理由 |
| 材料与构造真实性 | AEST-MAT-01 | 方案、深化 | 合并材料，定一主两辅 |
| 光影与季节 | AEST-LIGHT-01 | 方案、深化 | 补足 9 组并含低角度 |
| 色彩克制 | AEST-COLOR-01 | 方案、深化 | 删色相、提主色占比、压高饱和 |

这些规则只判「是否做了」，不判「做得好不好」。做得好不好由 §6 的评审话术在汇报现场判定，两者不可互相替代。

## 8. 常见伪论证与拆解

| 伪论证 | 问题 | 拆解问法 |
|---|---|---|
| 「这是当地传统做法」 | 传统不等于适用，也不等于可施工 | 传统做法解决的是哪个气候／材料／工艺问题？今天的条件变了吗？ |
| 「材料越少越高级」 | 少不等于对，可能只是没做完 | 少到 1 种时，用什么区分不同功能与不同界面？ |
| 「光影是灵魂」 | 无法判定 | 冬至 09:00 这张图上，主要活动场地有多少比例在阴影里？ |
| 「色彩要有活力」 | 活力不等于多色 | 主色是哪个？占比多少？高饱和用在哪一处？ |
| 「业主喜欢这样」 | 业主偏好可改，硬伤不可改 | 先答指标与空间是否成立，再谈偏好；偏好不得推翻安全与法规 |
