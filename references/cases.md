# 案例库与调用手册（cases）

本文件是手法库，不是风格目录。它的唯一用途：当设计问题出现时，找到 2–4 个可迁移的动作，并说明改写方案是什么。

## 0. 三条硬纪律（违反即视为不合格引用）

1. **只借手法，不复制形式。** 借的是「用一条连续地面消解高差」这个动作，不是把别人的曲面屋顶原样搬过来。凡输出里出现「外形类似某某」即判定违规。
2. **给先例时必须同时说明借的是哪一层。** 每处引用都要写明层（结构逻辑／空间组织／场地关系／材料细节／运营时间，见 §3）与「改写了什么」。缺「改写了什么」视为抄袭风险。
3. **不得把未建成方案说成已建成。** 引用前核实状态（建成／在建／方案），并在案例卡里注明核实来源；标注 [待核] 的团队与年份未核对前，不得作为事实陈述。

## 2.3 手法深读（六组，按层组织）

每组给四段：借什么／怎么借／移用条件／失效条件。失效条件比移用条件更重要——它是评审时用来否定一个引用的依据。

### A 组 · 结构逻辑（借自 C03、C07、C08）

| 段 | 内容 |
|---|---|
| 借什么 | 用一个可复制的结构单元生成整栋建筑，而不是先画外形再找结构 |
| 怎么借 | 先定单元跨度与重复次数，再让平面、立面、铺装都从这个单元推导出来 |
| 移用条件 | 本项目柱网能被同一单元整除；单元跨度落在本地钢结构或混凝土的经济区间内 |
| 失效条件 | 单元跨度过大导致用钢量失控；或单元只出现在立面上而结构与它对不上 |
| 改写示例 | 借 C03 的结构单元重复：把拱单元改为 8.4m×8.4m 的梁柱单元，重复 6×4 次，取消曲面 |

### B 组 · 空间组织（借自 C01、C05、C25）

| 段 | 内容 |
|---|---|
| 借什么 | 用一条序列或一条环路把散落功能串成一个可记忆的空间结构 |
| 怎么借 | 先排序列（入口—收—放—收—出口），再把功能挂到序列上，最后才定形式 |
| 移用条件 | 本项目有两个以上公共空间需要被感知为「一组」 |
| 失效条件 | 序列只能在总图上看懂，走进建筑感受不到；或序列被消防疏散打散 |
| 改写示例 | 借 C01 的水院组织轴线：本项目改为一条 4.5m 宽下沉步道串三个庭院，取消水院 |

### C 组 · 场地关系（借自 C10、C13、C20）

| 段 | 内容 |
|---|---|
| 借什么 | 用抬升、下沉或堆山改变地面的数量与标高，而不是在平地上摆体量 |
| 怎么借 | 先定 ±0.00 与顶板标高，再定覆土厚度，最后才排功能与种植 |
| 移用条件 | 场地有高差，或有地下室顶板可被利用 |
| 失效条件 | 抬升后消防车道进不去；覆土厚度不够种计划中的乔木；土方无法就地平衡 |
| 改写示例 | 借 C20 的剖面式地形折叠：本项目用开挖土方在西北侧堆 3.5m 高草坡，兼作隔声 |

### D 组 · 材料细节（借自 C02、C07、C16）

| 段 | 内容 |
|---|---|
| 借什么 | 让材料的表现方式等于它的构造方式（砌法、本色、旧材的真实痕迹） |
| 怎么借 | 先定构造（砌、挂、浇），再定表现（缝、色、肌理），禁止反过来 |
| 移用条件 | 本地有对应工艺与工匠；或可打样试做 |
| 失效条件 | 本地无工艺；材料本色在本地气候下会迅速污损；旧材来源与强度不可控 |
| 改写示例 | 借 C02 的砌筑即装饰：本项目用本地页岩砌筑，错缝 1/2 砖，取消贴面砖 |

### E 组 · 植被与时间（借自 C12、C14、C19）

| 段 | 内容 |
|---|---|
| 借什么 | 把养护预算与季节当成设计条件，而不是建成后再补 |
| 怎么借 | 先定年度养护预算与养护人手，再选植物与做法（草坪、花境、自演替） |
| 移用条件 | 有明确的运维主体与预算 |
| 失效条件 | 预算低于自演替所需的起步期投入；或洪水位与苗木耐淹性不匹配 |
| 改写示例 | 借 C12 的乡土与自演替：本项目取消 3000 平方米草坪，改为本地草本地被 + 3 年封育期 |

### F 组 · 尺度与单元（借自 C08、C18、C26）

| 段 | 内容 |
|---|---|
| 借什么 | 用一套模数与一种重复构件统一大面积场地或多栋建筑 |
| 怎么借 | 定一个基准模数，让铺装、构件、种植池、家具都按它排 |
| 移用条件 | 场地面积大于 1 公顷，或建筑多于 3 栋 |
| 失效条件 | 模数与场地边界冲突，边角出现大量碎块；重复构件造价高于定制 |
| 改写示例 | 借 C08 的模数化单元：本项目以 600mm 为景观模数、300mm 为建筑模数，全部向上取整 |

## 3. 五个可借的层（引用必须落到其中一层）

| 层 | 借的是什么 | 借错的典型 | 判据 |
|---|---|---|---|
| 结构逻辑 | 单元重复如何生成整栋、跨度与柱网如何互换 | 把曲面形状当结构逻辑借走 | 能在本项目的柱网上重算一遍 |
| 空间组织 | 序列、视线、公共与私密的层级 | 抄平面布局 | 说清本项目哪两处空间关系因此改变 |
| 场地关系 | 建筑与地形、水、道路、边界的相对动作 | 抄总图构图 | 给出本项目的一处标高或退线变化 |
| 材料细节 | 材料本色、砌法、收口、节点做法 | 指定同款材料品牌 | 能落到一张 1:20 节点 |
| 运营时间 | 分期、可维护性、季节变化、低成本 | 当成「以后再说」 | 给出运维预算或分期表 |

层与自检脚本的 PLAN-CASE-01 对应：design.json 的 references[].layer 必须是上表五层之一，且最多 3 条、来自不同层。

## 5. 引用格式（固定四段，缺一不合格）

```
案例名（建筑师／景观师，年代，地点）— 借用的手法：X（哪一层）。
为什么适用：Y（本项目哪条场地证据或指标约束）。
改写了什么：Z（尺寸、材料、标高、模数、分期中的具体变化）。
状态：建成／在建／方案（核实来源）。
```

正例与反例：

| 反例 | 病因 | 正例 |
|---|---|---|
| 「类似苏州博物馆的现代中式」 | 只给风格词 | 「借 C01 的几何转译（界面）：把本项目的坡屋顶轮廓抽象成 1.2m 模数的折板女儿墙，改写点为取消坡屋顶本体、只保留轮廓线」 |
| 「学高线的种植」 | 未说借哪一层 | 「借 C16 的条带式植被交替（材料细节）：在本项目 6m 宽的线性绿带里按 4 条 1.5m 带交替，改写点为把观赏草换成当地耐旱品种」 |
| 「像天目里那样」 | 抄形式 | 「借 C08 的架空底层·连续地面（场地关系）：本项目把首层抬高 4.5m 形成连续地面，改写点为下方改为风雨操场而非商业」 |
| 「参考达士岭的空中花园」 | 未算结构可行性 | 「借 C26 的环线与多路径（空间组织）：本项目设 1 道空中连桥而非 2 道，改写点为连桥跨度压到 24m 以适配本地钢结构造价」 |

## 6. 案例卡模板（每个引用一张，落 out/concept/C06_参考案例卡.md）

| 字段 | 填法 | 缺失后果 |
|---|---|---|
| 案例 ID | C01–C28 | 无法检索 |
| 名称（作者，年代，地点） | 与原表一致；[待核] 项照抄标记 | 事实错误 |
| 层 | 五层之一 | PLAN-CASE-01 判不合格 |
| 借用的手法 | 一句话，动词开头 | 变成风格描述 |
| 本项目为什么要它 | 指向一条场地证据或指标约束 | 无依据的引用 |
| 改写了什么 | 具体到数值或做法 | 抄袭风险 |
| 状态与来源 | 建成／在建／方案 + 核实来源 | 违反硬纪律 3 |

## 7. 使用纪律与常见误用

| 纪律 | 做法 |
|---|---|
| 数量上限 | 一个方案最多 3 个案例，且不同层 |
| 禁止清单式罗列 | 不在汇报里放 10 张案例照片；每个案例必须对应一处本项目改动 |
| 禁止二手转述 | 年代、作者、状态以官方公告或事务所作品集为准；有出入时标 [待核] 并注明来源 |
| 禁止跨气候区直接搬 | 苗木、构造、遮阳做法跨气候区必须先做适配说明 |
| 禁止用案例替代指标 | 「达士岭做到了」不构成容积率可以突破的理由 |

| 常见误用 | 后果 | 纠正 |
|---|---|---|
| 把案例当风格参照 | 形式抄袭、评审被质疑原创性 | 改问「它解决了哪个技术问题」 |
| 只借最显眼的构件 | 结构与造价不成立 | 先借结构逻辑，再借形式结果 |
| 一个案例反复用 | 单一谱系 | 换到不同层的第二个案例 |
| 拿未核实的团队与年份当事实 | 事实错误 | 保留 [待核] 或改写为「以现行资料核对」 |
| 借了手法却写不出改写点 | 抄袭风险 | 强制补「改写了什么」一行，写不出就换案例 |
