# codes-cn · 中国规范与方案阶段指标执行手册

> **读者**：被技能调用的 AI 执行者。本文件是操作手册，不是规范汇编。
> **用法**：出现指标、消防、无障碍、绿地率、日照、停车、退距等硬约束时，按 §2 查「该查哪本」，按 §3 算「怎么算」，按 §4 决定「算不成立时先改什么」。
> **三条硬规则**
> 1. 不写条文号。只写「规范全名 + 指标名」。需要精确引用时留空给人工补。
> 2. 不给全国统一的地方性数值。容积率、密度、绿地率、停车配建、退线、限高必须逐城市查地方文件。
> 3. 标 [待核] 的编号或年份不得当作确定值使用；输出中必须原样保留 [待核] 标记。

## 1. 三层效力结构

### 1.1 三层是什么

| 层级 | 编号形态 | 发布者 | 效力 | 方案阶段作用 | 引用方式 | 常见误用 |
|---|---|---|---|---|---|---|
| **第一层：强制性工程建设规范** | GB 55xxx（2021 年起集中发布），名称多为「XX通用规范 / XX项目规范」 | 住建部 | **全文强制**，全部条文必须严格执行，不设「宜」「可」的宽松解释空间 | **底线校核**。凡与本层冲突，一律以本层为准 | 「GB 55xxx《全名》+ 指标名」 | 拿旧标准里的旧数值覆盖本层；把本层当「参考」 |
| **第二层：国家标准 / 行业标准** | GB / GB/T / CJJ / CJJ/T / JGJ | 住建部、相关行业主管部门 | 推荐性或非强制；其中历史遗留的「黑体字强制性条文」在对应 GB 55xxx 实施后**已部分废止** | **细化做法与计算方法**（日照怎么算、绿地怎么分类、面积怎么算、车位怎么排） | 「编号《全名》+ 指标名」，并注明「以现行版本为准」 | 整段套用旧标准的强制性条文；把 GB/T 当强制 |
| **第三层：地方法规与规划管理技术规定** | 各市《城市规划管理技术规定》《停车配建标准》《绿地率计算规则》《日照分析技术规程》等 | 地方政府 / 规划主管部门 | **效力优先于国标**（地方更严时从严） | 容积率、密度、绿地率、停车配建、退线、限高的**实际执行值 90% 来自本层** | 「城市名 + 文件名 + 指标名」 | 用全国统一数值代替地方值；忽略「地方更严」的条款 |

### 1.2 优先级规则（4 条，可判定）

| # | 规则 | 判定方法 | 反例 |
|---|---|---|---|
| R1 | **地方 > 国标 > 行业** | 三个来源对同一指标都给了值时，取地方值 | 用 GB 50180 的绿地率覆盖某市规定的更高下限 |
| R2 | **从严者优先** | 两个来源都给值时，比较后取更严格者（绿地率取大、退线取大、车位取多、容积率取小） | 因「国标没这么严」而放行 |
| R3 | **GB 55xxx 优先于旧标准的强制性条文** | 第一层与第二层冲突时，一律按第一层执行，并提示旧标准对应强制性条文可能已废止 | 用 GB 50016 的旧数值解释 GB 55037 已调整的要求 |
| R4 | **无值即缺口** | 三个来源都查不到该项目所在城市的值时，**报缺口**，不得填经验值 | 「一般按 30% 算」 |

**R2 的「从严」比较算法（3 步）**
1. 把每个来源的值写成「指标名 = 值 + 单位 + 口述口径」，口径不一致的先换算到同一口径（见 §3.2）。
2. 按指标方向分组：**越大越严**（绿地率、退线、间距、无障碍净宽、转弯半径）/ **越小越严**（容积率、密度、限高、疏散距离、坡度）。
3. 取同组中最严值；两个来源口径无法换算时，按 R4 报缺口，不做四舍五入的「折中」。

### 1.3 冲突裁决流程（5 步，顺序不可换）

1. **定位层级**：把冲突双方各归到 §1.1 的三层之一。
2. **查是否已被替代**：第一层实施后，旧标准的强制性条文可能已废止。查该标准正文前言与住建部公告；查不到则标 [待核]。
3. **套用 R1–R3**：先比层级，同层级比严格度。
4. **落到指标**：把结论翻译成「指标名 = 值」，写进指标表，注明来源文件名与版本年份。
5. **留痕**：在设计说明的「依据」栏写「取值来源 + 冲突项 + 裁决理由」，三项缺一即视为未裁决。

### 1.4 引用纪律（禁止条文号）

| 允许 | 禁止 | 正确写法 |
|---|---|---|
| 规范全名 + 指标名 | 「GB xxxxx 第 x.x.x 条」这类具体条号（本技能一律不写，见上方 §1.4 标题） | 「按 GB 55037《建筑防火通用规范》关于消防车道净宽的要求核算」 |
| 编号 + 版本年份 + 指标名 | 自行推论的条号、章节号 | 「按 GB/T 50353《建筑工程建筑面积计算规范》的计容口径核算阳台面积」 |
| 「常用控制值」「通行做法」并注明须核对 | 把常用值写成规范值 | 「车道净宽常用控制值 ≥4m，须按现行规范与地方规定核对」 |
| 带 [待核] 的编号 | 去掉 [待核] 冒充已核实 | 「GB 55038-2025《住宅项目规范》[待核：编号年份与实施日期]」 |

## 3. 方案阶段 9 项指标

> **总规则**：本表「常见限值区间」列全部是**常用控制值**，用途是「先按此做指标预估、留出余量」，**不是**可以用来出报建图的数值。每一项的最终值必须以项目所在城市的地方规定为准（下表统一记作「各地不同，须核地方规定」）。

### 3.1 指标总表

| # | 指标 | 计算公式 | 单位 | 数据来源 | 常见限值区间（各地不同，须核地方规定） | 算不出来时怎么办 |
|---|---|---|---|---|---|---|
| 1 | 容积率 | 计容建筑面积 ÷ 建设用地面积 | 无量纲 | 控规图则给定上限；计容口径按 GB/T 50353 与地方面积规则 | 由控规给定；方案宜留 3%–5% 余量 | 先分清「计容/不计容」清单再算；仍算不出则报缺口并列出缺的输入（地界、计容口径、层数） |
| 2 | 建筑密度 | 建筑基底面积 ÷ 建设用地面积 | % | 控规给定上限；地方规定定义「基底」计入规则 | 由控规给定 | 逐栋画基底外轮廓再求和；连廊、地下车库出入口、门卫的计入规则未定时报缺口 |
| 3 | 绿地率 | 绿地面积 ÷ 建设用地面积 | % | GB 55014-2021、GB 50180-2018、地方绿地率计算规则 | 居住区常见口径：新区 ≥30%、旧区改造 ≥25% [待核，以 GB 55035-2022 与地方规定为准] | 先按 CJJ/T 85 分类量算，再分别列地面/覆土/屋顶三类；水面与屋顶折算系数未定则报缺口 |
| 4 | 日照间距 / 日照标准 | 受遮挡建筑在有效日照时间带内获得的日照时数 | h（时长）；m（间距） | GB 55016-2021、GB/T 50947-2014、地方日照分析规程 | 住宅按气候区取大寒日或冬至日，时数 1–3h 不等 [待核，逐城市查] | 缺参数（时间带、起算高度、判定面）时**不得估算**：输出「日照未校核」并列出缺失参数清单 |
| 5 | 消防车道与登高面 | 车道中心线长度/闭合性 + 净宽净高 + 转弯半径 + 登高面尺寸与距外墙距离 | m | GB 55037-2022、GB 50016-2014（2018 年版）[待核：有效范围] | 净宽 ≥4m、净高 ≥4m；尽头式设回车场，常用 12m×12m、高层宜 15m×15m、重型车 18m×18m；登高操作场地常用 ≥15m×10m，距外墙 5–10m，坡度 ≤3%（**均为常用控制值，须按现行规范核对**） | 环形不成立时先画中心线验算转弯半径；半径不足则报缺口并给「改体量/改车道」两套选项，不得把车道画到红线外 |
| 6 | 无障碍 | 连续无障碍路径的长度、坡度、净宽、高差 | m / % / mm | GB 55019-2021、GB 50763-2012 | 坡道坡度常用 ≤1:12，净宽 ≥1.2m，休息平台 ≥1.5m，扶手 0.85m 与 0.65m 双层；室内外高差无防水要求处宜 ≥15–30mm，无障碍入口处高差 ≤15mm 并坡化（**须以 GB 55019-2021 核对**） | 逐个出入口画路径，标每段坡度与宽；被车位/花池截断即判不成立，报缺口并给改线方案 |
| 7 | 停车配建 | 按功能分区列表：各功能面积 × 地方配建指标（车位/百㎡ 或 车位/户） | 车位（机动车/非机动车分列） | **地方《停车配建标准》（无全国统一值）**；设计按 JGJ 100-2015 | 必须逐城市查；另需含充电桩比例、无障碍车位、访客车位、装卸车位 | 查不到地方标准即报缺口，禁止套用其他城市数值；先给「按上限/下限」两套试算 |
| 8 | 建筑高度 / 限高（附加） | 室外地坪至屋面面层/檐口高度（坡屋顶、女儿墙、机房按地方规则计入） | m | 地方规定；GB 55031-2022 的分类与高度定义 | 由控规与航空/微波通道给定 | 各栋分别标注；机房与设备层的计入规则未定时按「宽口径」先算，并注明 |
| 9 | 建筑退线 / 间距（附加） | 建筑外墙（含阳台、飘窗按地方口径）至用地红线/道路红线/相邻建筑的距离 | m | 地方规定；消防间距另按防火规范 | 由地方规定给定；消防间距另核 | 地下室外墙退线常被漏算：先画地下室轮廓再核退线；缺地方规定时报缺口 |

### 3.2 三个最易出错的口径（先定口径，再算数值）

| 口径 | 分叉点 | 差值量级 | 处置 |
|---|---|---|---|
| **面积口径**（决定容积率） | 阳台（半计/全计/不计）、飘窗（净高阈值）、设备层（层高与面积阈值）、架空层（是否计容）、半地下室（埋深比阈值） | 同一方案按宽/严口径可差 5%–15% | 算两遍：宽口径、严口径。差值 >5% 即「口径风险高」，必须书面确认后再出图 |
| **绿地口径**（决定绿地率） | 水面是否计入、覆土深度门槛、屋顶绿地折算系数与上限、树阵式铺装是否计入 | 可差 3%–10% | 绿地率计算书必须分列：地面绿地 / 覆土绿地 / 屋顶绿地 / 水面，四项分开报，让审批方选口径 |
| **配建口径**（决定车位数） | 计费面积口径、充电桩比例、无障碍车位、访客/装卸车位是否单独计 | 可差 5%–20% | 按「功能—面积—指标—车位数」四列表算，每一行标数据来源文件 |

### 3.3 指标自检闸门（顺序固定，前一项不成立则后项作废）

**用地指标 → 日照 → 消防 → 无障碍 → 绿地率 → 停车 → 其他专项**

| 闸门 | 通过判据 | 不通过的动作 |
|---|---|---|
| 用地指标（容积率/密度/高度/退线） | 9 项指标全部有计算过程与来源 | 停止出图，回 §4 |
| 日照 | 有计算参数（日期/时间带/起算高度）+ 不满足户清单（无则不适用需说明原因） | 改体量或改布局，不得改参数 |
| 消防 | 车道能闭合、转弯半径达标、登高面一侧干净（无雨棚/树木/架空层） | 改体量或改车道，不得把车道画到红线外 |
| 无障碍 | 每个建筑出入口都有连续无障碍路径，逐段有坡度与宽度 | 改出入口或加坡道；不得在车位上画坡道 |
| 绿地率 | 分类量算 + 四项分列 + 折算系数有出处 | 改硬质范围或改覆土，不得虚增屋顶绿地 |
| 停车 | 车位数有逐行计算过程 + 地方标准出处 | 查地方标准；不得「少画」 |

## 4. 指标不成立时的处置顺序

### 4.1 判断树（按顺序执行，任一步成立即停在该步，不得跳级）

**Q0 · 分类：这个不成立项是「不可谈判项」还是「可调项」？**

- **不可谈判项**（安全与法定底线）：消防车道/登高面/防火分区/疏散、日照标准、无障碍通行、结构安全、防洪排涝、地下室抗浮与防水设防、文保建控高度、蓝线绿线。
  → **只能进 A3（改体量/改布局）**。禁止用 A1（改口径）或 A2（改功能）绕过。
- **可调项**：容积率、建筑密度、绿地率、停车配建、建筑高度与退线（在控规与地方规定允许范围内）、非计容面积口径。
  → 继续 Q1。

**Q1 · 口径是否算错或有歧义？→ 动作层 A1：修口径**

1. 查三个必查口径：面积口径（§3.2 第一行）、绿地口径、配建口径。
2. 宽/严各算一遍；差值 >5% 说明口径风险高，先书面确认口径再往下走。
3. **停止条件**：修正口径后指标成立 → 停。写计算书 + 口径声明（用了哪个口径、依据哪个文件）。
4. 未停：**剩余缺口 = 原缺口 − 口径可回收量**，带着剩余缺口进 Q2。

**Q2 · 功能与配比能否调整而不动体量骨架？→ 动作层 A2：调功能**

1. 只动「内容」不动「壳」：功能置换、面积配比调整、非计容功能下地或入架空、分期切分、共享空间合并、辅助面积压缩。
2. **判定**：调整后柱网、核心筒位置、防火分区边界、登高面朝向都不变 → 属 A2；任一项要动 → 直接跳 A3。
3. 典型可回收量：功能置换 3%–10%；下地/入架空 5%–15%（受地下室成本、覆土厚度、消防限制）。
4. **停止条件**：指标成立 → 停，出调整前后的面积对照表。

**Q3 · 体量与布局 → 动作层 A3：改体量**

顺序固定，每次只改一项，改完立刻复算全部 9 项指标（日照、消防、绿地率会联动）：

1. **层数 / 层高** —— 最便宜的改法，先做。
2. **进深 / 面宽** —— 同时改变体形系数与日照间距，一次只能改一个方向。
3. **栋数 / 间距** —— 会重排总图，触发绿地和消防复算。
4. **柱网** —— 只在车库车位效率或结构经济性不成立时才动（JGJ 100-2015 直接约束）。
5. **位置 / 朝向** —— 最后手段，等于重做总图。

**代价**：总图、消防、日照、立面、地下车库全部重做；按「每改一项 = 1 轮完整复核」计工期。

**Q4 · 用地与规划条件 → 动作层 A4（越权，必须外部决策）**

- 内容：申请调整控规、拆分或合并地块、变更用地性质、分期报建、容积率转移或奖励。
- **只能由业主 + 规划主管部门决策**；设计方只提供「技术论证包」（现状问题、拟调指标、影响评估、替代方案对比）。
- **禁止**：设计方自行按调整后的指标出图；禁止在图上标注「待批容积率」而不写申请状态。

### 4.2 四个动作层的代价对照

| 动作层 | 触及范围 | 返工代价 | 谁有权决定 | 典型可回收量 | 何时禁止使用 |
|---|---|---|---|---|---|
| A1 修口径 | 计算书、指标表 | 半天–1 天 | 主创 + 报建负责人 | 5%–15% | 不可谈判项（消防/日照/无障碍）；地方规定已明确口径时 |
| A2 调功能 | 平面功能布局、面积表 | 2–5 天 | 主创 + 业主 | 3%–15% | 会动核心筒/柱网/防火分区时；业主已锁定功能配比时 |
| A3 改体量 | 总图、平立剖、车库、指标全表 | 1–3 周 | 主创 + 业主 | 由缺口定 | 用地已批、方案已报审且不允许变更时 |
| A4 改用地条件 | 用地与规划条件本身 | 数月（审批周期） | 业主 + 规划主管部门 | 由批复定 | 设计方自行决定时（越权） |

### 4.3 指标 × 动作矩阵（✓ 可用 / △ 有条件 / ✗ 禁止）

| 指标 | A1 修口径 | A2 调功能 | A3 改体量 | 说明 |
|---|---|---|---|---|
| 容积率 | ✓ | ✓ | ✓ | 三步都可用；先用 A1 排除面积口径误差 |
| 建筑密度 | △ | ✓ | ✓ | 口径余地小（基底计入规则多为地方明文） |
| 绿地率 | ✓ | ✓ | ✓ | 优先 A1（分类与折算）+ A2（硬质范围），最后才压建筑基底 |
| 日照 | ✗ | △ | ✓ | **参数不得改**；只能改体量、朝向、间距 |
| 消防车道/登高面 | ✗ | △ | ✓ | 不得把车道画到红线外或借市政道路（除非取得书面许可） |
| 无障碍 | ✗ | ✓ | ✓ | 入口位置与坡道布置可调，坡道不得占用车位 |
| 停车配建 | ✓ | ✓ | △ | A1 查地方标准；A3 只影响地下车库轮廓 |
| 建筑高度/限高 | △ | ✓ | ✓ | 机房与设备层的计入口径可查；不得「藏层」 |
| 退线/间距 | ✗ | △ | ✓ | 退线是法定距离，不可用口径规避 |

### 4.4 禁止的「伪解法」（命中即判定方案不成立）

| 伪解法 | 判定方法 | 后果 |
|---|---|---|
| 少画车位 | 用配建公式算出的车位数 ≠ 图上车位数 | 报建退回；车库后期加层不可行 |
| 把消防车道画到红线外 / 借用市政道路 | 车道中心线超出用地红线且无书面许可 | 消防审查不通过；建成后车辆进不去 |
| 登高面一侧设大雨棚/树木/架空层 | 在登高面范围内叠图检查 | 无法扑救；验收不通过 |
| 用屋顶绿地充抵地面绿地率 | 绿地率计算书未分列四项、折算系数无出处 | 指标虚高；地方核查时清零 |
| 把计容面积藏进「设备层」 | 该层高与面积是否超过地方规定的设备层阈值 | 被判违规加建，整改拆除 |
| 退线按「围墙退线」而非建筑外墙 | 量建筑外墙（含阳台）到红线的距离 | 规划核实不通过 |
| 用水面充当调蓄容积 | 是否有调蓄计算（容积、重现期、溢流） | 暴雨内涝；验收后返工 |
| 日照用非标时间带/起算高度 | 对照 GB/T 50947-2014 与地方规程逐项核参数 | 分析结论无效，方案重做 |
| 把无障碍坡道画在车位上 | 坡道范围与车位范围叠图 | 无障碍流线断裂 |

### 4.5 处置记录格式（必须写进设计说明）

| 指标 | 缺口 | 处置层（A1/A2/A3/A4） | 处置内容 | 处置后剩余缺口 | 决策人 | 日期 |
|---|---|---|---|---|---|---|
| 容积率 | 超出 0.12 | A1 + A2 | 阳台改按半计；设备层下地 | 0（成立） | 主创 / 业主 | — |
| 绿地率 | 缺 2.1% | A3 | 缩减 1 栋基底，补 3 株大乔木 | 0（成立） | 主创 | — |
| 日照 | 北侧 12 户不足 | A3 | 降低西栋 2 层 | 0（成立） | 主创 / 业主 | — |

**记录纪律**：一行一个指标；「剩余缺口」必须写数值，不写「基本满足」；决策人必须是具体角色，不写「各方」。
